ONE-TIME DEVICE SETUP

Give your microphone a secure connection.

Browsers require a trusted HTTPS connection to record from another device. Install this server’s public certificate once on each device, then open the secure studio.

If you’re using the server PC itself, localhost also supports recording.

  2. Trust it on this device

    iPhone / iPad

    Open the downloaded certificate and install its profile in Settings → General → VPN & Device Management. Then go to Settings → General → About → Certificate Trust Settings and enable full trust for Voice room Local CA.

    Apple’s certificate trust instructions ↗

    Android

    In Settings, search for Install a certificate. Choose CA certificate and select the downloaded file. The option is usually under Security & privacy → More security settings → Encryption & credentials; names vary by device. Restart the browser afterward.

    Windows

    Open the downloaded certificate, choose Install Certificate, select Current User, then place it in Trusted Root Certification Authorities. Confirm the certificate name and fingerprint. Restart your browser if necessary.

    Mac

    Open the certificate in Keychain Access and add it to your login keychain. Open Voice room Local CA, expand Trust, and allow it for SSL. Your Mac may ask for your password to confirm the change.

    Only trust the certificate from your own server. This creates a local trust authority; its private key stays on the server. You can remove “Voice room Local CA” from your device’s certificates when you no longer use this service.

  3. Record in the secure studio

    Open secure studio ↗

    Choose Transcribe audio → Record microphone, allow microphone access, then stop and transcribe. A certificate warning means device setup is not complete.
